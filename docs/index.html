What you are downloading

Nothing installs unasked.First run asks one question — set everything up now, or set each tool up the first time you open it. Every step says what it will download and how big it is. Files and media work with no network at all.
Windows gets everything.macOS and Linux run the hub, agents, files and media. Desktop control is Windows-only, and is hidden elsewhere rather than offered and broken.
Agents need a model.Either a provider key — several have free tiers, and you paste it into the hub, not a terminal — or an existing Claude or Codex subscription, which needs no key. A local model through Ollama also works.
Your work stays here.The hub runs on your PC and binds to loopback; other devices reach it over your own Tailscale network. Agents work in a private copy of your repo and nothing is written to it until you read the diff and approve.

How to set up private device access

1Install Tailscale on this PC and on your phone.
2Sign both into the same private network.
3Open the hub address and save the bookmark to your home screen.
Agent Hub runs on your own machine, on your own private network. Nothing it does leaves your tailnet.
