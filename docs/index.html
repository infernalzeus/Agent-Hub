AUTONOMOUS LLM

Your project. Your decision.

Live

  1. No form to learn. A sentence typed on the board, spoken to TALK from your phone, or the first step of a saved automation.

  2. Most questions never need an agent. The router walks a ladder and stops at the first rung that can answer, so you are not paying a model to tell you the time.

  3. One planner reads the ask and proposes the pieces. Briefs that do not depend on each other run side by side; one that needs earlier work waits for it.

  4. Each mission gets its own git worktree on its own branch. Your files do not change while it runs, and a provider hiccup moves the run to the next model instead of failing it.

  5. An agent at a real fork does not guess. The run parks, the question reaches whichever device is open, and your answer resumes the same mission. It never asks for a password or a key.

  6. When the work is done the mission stops with the diff beside it. This is the one decision the system will not make for you.

  7. Apply merges the branch into your repo. Discard removes the copy and the branch. An automation waiting on this carries on only if you applied.

PC CONTROL

It asks before it presses anything.

Unit-tested

  1. “Open Apple Music and play my liked songs.” Speak to TALK or type it. No scripting, no recorded macro to maintain.

  2. Windows MCP reads the controls on screen, so it finds Play by what it is, not by where it was last time.

  3. It shows the control it found and waits for your yes before touching anything.

  4. Windows MCP presses the control. Shell, registry, file and process tools are switched off, so it can drive apps but not rewrite the machine.

  5. A press only counts if the window changed. A replay that leaves the window as it was is not counted as a success.

  6. A run that worked is saved as a routine. It starts as a candidate and is trusted only after it has worked twice.

MEDIA VAULT

Download, convert, browse, receive.

Live

  1. Paste a link or ask in plain words. The download runs on your PC, as audio or as video.

  2. ffmpeg turns it into the format you chose, on your PC.

  3. The result is saved to the folder you picked, not to someone else's server.

  4. Browse it here, or copy it from your phone. Files you send from your phone land in your inbox on the PC.

GIT GRAPH

Every project as one dot.

Live

  1. The map finds your projects in the folders you chose and draws one dot for each, read straight from git.

  2. See which projects have changes waiting and which agent copies have been left behind.

  3. Tap a dot to see exactly what an agent changed, including the copy it is working in right now.

  4. Merge the agent's branch, or leave it. Nothing is merged for you.

AGENTS + SKILLS

A team you can read and extend.

Live

  1. Smith is the helper you talk to; the request goes to the right tool or agent.

  2. Neo drafts an agent from your description. You review the role, then add it to your team.

  3. Agents have their own roles and hand work to each other. The planner splits a mission into briefs and hands them to agents in private copies.

  4. Give an agent a new ability by adding a skill, or write your own for the work you want done.

  5. The Doctor proposes a repair to the Hub and hands the change to you. You review it, then press APPLY.
